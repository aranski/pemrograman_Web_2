# Sistem Pendaftaran Seminar Kampus

**Sistem Informasi Pendaftaran Seminar Berbasis Web**  
Mata Kuliah: Pemrograman Web 2  
Framework: Laravel 13.x

---

## 📌 Deskripsi Project

Website ini dibuat untuk memudahkan mahasiswa mendaftar seminar secara online serta memudahkan panitia/admin dalam mengelola data seminar dan peserta. Project ini menekankan implementasi **Input → Proses → Output** yang terhubung penuh ke database.

---

## ✨ Fitur Utama

### Untuk Guest
- Melihat daftar seminar aktif
- Melihat detail seminar
- Pencarian seminar

### Untuk Peserta (Mahasiswa)
- Register & Login
- Mendaftar seminar
- Melihat riwayat pendaftaran
- Membatalkan pendaftaran

### Untuk Admin
- CRUD Seminar
- Manajemen Pendaftaran (Setujui / Tolak)
- Laporan peserta per seminar
- Dashboard statistik

---

## 🛠️ Teknologi yang Digunakan

- **Backend**: Laravel 13.x
- **Frontend**: Blade + Tailwind CSS
- **Autentikasi**: Laravel Breeze
- **Database**: MySQL
- **Version Control**: Git + GitHub
